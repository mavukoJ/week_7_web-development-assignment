
# SpendWise - Smart Budget Tracker

## Project Description

SpendWise is an interactive personal finance application that helps users manage their money, track expenses, and monitor their budgets.

Users can set a monthly budget, record multiple expenses, delete expense records, and view their remaining balance automatically.

The application is built using HTML, CSS, and JavaScript and hosted online through Netlify.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Netlify

## Main Features

- Set a monthly budget.
- Add multiple expenses.
- Calculate total expenses.
- Calculate remaining balance.
- Display budget status.
- Delete individual expenses.
- Clear all expenses.
- Responsive design.
- Dynamic dashboard updates.

## Deployment Process Summary

The application was deployed using GitHub and Netlify.

The deployment process involved:

1. Organizing the project files.
2. Creating a public GitHub repository.
3. Uploading the project files to GitHub.
4. Creating a Netlify account.
5. Connecting the GitHub repository to Netlify.
6. Configuring the deployment settings.
7. Deploying the website.
8. Customizing the Netlify site name.
9. Testing the live application.
10. Updating the project and pushing changes to GitHub.
11. Verifying automatic deployment through Netlify.

## Continuous Deployment

SpendWise is connected to GitHub through Netlify.

When changes are pushed to the main branch, Netlify automatically detects the new commit and deploys the updated website.

This makes updating the live application easier.

## Challenges Encountered During Deployment

### 1. Connecting GitHub to Netlify

Solution: Authorized Netlify to access the GitHub repository.

### 2. Deployment Configuration

Solution: Used the project root as the publish directory and left the build command blank because the project uses plain HTML, CSS, and JavaScript.

### 3. Customizing the Website Name

Solution: Changed the default Netlify subdomain to a meaningful SpendWise name.

### 4. Testing Automatic Deployment

Solution: Made a visible update to the website, pushed it to GitHub, and checked that Netlify published the changes.
